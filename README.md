
# QSkill Python Development

This repository contains Python projects completed during the QSkill Python Development program.

## Projects

### 1. CSV Analysis
- Read and analyze CSV files using Python and Pandas.
- Perform data cleaning and basic statistics.

### 2. House Price Prediction
- Machine Learning project for predicting house prices.
- Uses Python, Pandas, NumPy, and Scikit-Learn.

### 3. Matrix Operations Tool
- Perform matrix addition, subtraction, multiplication, and transpose operations.
- Implemented using Python and NumPy.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Google Colab
